## Deskripsi Praktikum
Praktikum ini membahas dasar pemrograman server-side menggunakan PHP, mulai dari variabel, operator, percabangan, perulangan, function, hingga pengolahan data menggunakan metode GET dan POST.

## Tujuan Praktikum
1. Memahami konsep pemrograman server-side menggunakan PHP.
2. Mengenal sintaks dasar PHP.
3. Menggunakan variabel, operator, percabangan, dan perulangan.
4. Membuat dan menggunakan function.
5. Memproses data formulir dengan GET dan POST.
6. Melakukan validasi input pengguna.
7. Membuat aplikasi formulir data mahasiswa sederhana.

## Cara Menjalankan Program

1. Buka XAMPP Control Panel.
2. Jalankan Apache dengan menekan tombol Start.
3. Pastikan folder `Lab7Web_PHP` berada di `C:\xampp\htdocs`.
4. Buka browser dan akses alamat berikut.
